# hspnv 动态学习笔画输入法

基于 **Rime / Hamster（元书）** 的五笔画输入方案，融合词组预测、真实语料联想、自学习调频、热词订阅等能力，让笔画输入更聪明、更顺滑。

> 拼音反查已移除（不再依赖字母键盘）。

---

## ✨ 功能特性

### 候选区纯净模式
- **无分词**：只预测单字候选
- **第 N 个分词符** → 只预测 **N+1 字词**（1 个分词符→二字词，2 个→三字词，以此类推）
- **无词命中**：自动回退 —— 保护分词符前已命中的词 + 末段按笔画重新定字（绝不回退数字、绝不留白）

### 词组预测
- 四字词在**第二次分词**时即可预测（输入「亡码'羊码'」直接预测「亡羊补牢」）
- 输入前 N 段 + 分词键，预测 N+1 字词（词库全量前缀匹配）

### 真实语料联想（四层模型）
- **万象 ARPA 语言模型训练**：从 419MB 万象 `.gram` 提取真实语料 n-gram，经词库分词重建词级 bigram/trigram，融入联想模型
- **自研短语库**：单前词 / 双前词 / 四连联想（生日快乐→心想事成、我想你→了）
- **unigram 兜底**：数据驱动的高频接续词表
- **用户历史预测**：librime-predict（predict_translator）基于上屏历史 n-gram
- 联想输出**精选 5 个**（提示而非菜单）

### 连打键
- 上屏后按「**连打**」键（皮肤第 3 行），连续上屏联想词成句
- 联想排除最近 6 个上屏词，连打不循环

### 以词定字
- 皮肤「**首**」键 / 「**末**」键：取候选词首字 / 末字
- 输入中 / 空输入联想状态下均可使用

### 自动上屏
- Rime 原生 `speller/auto_select`：候选唯一时自动上屏
- Lua 处理器 `auto_commit` 兜底（menu 就绪时下一键提交）

### 自学习 / 调频
- 上屏自动加频、30 天半衰期衰减（带下限保护）
- 上下文调频、衔接词优先、联想个性化提权
- 手动上移 / 下移 / 置顶 / 重置 / 降权（皮肤键触发）

### 词库与热词
- **白霜拼音**高质量词库（MNBVC 7.4 亿字语料重统计 + 归一化）作为主词库
- 热词订阅一键更新：`hotupdate`（百度热搜 / 头条热榜 / B站热榜 → 纯汉字过滤 → 自动入库）

```
├── stroke_bg5cgq_learning.schema.yaml   # 主方案配置

│   ├── segment_phrase.lua                # 主翻译器（候选/分词/联想/回退）
│   ├── words.lua                         # 主词库
│   ├── learning.lua                      # 自学习/调频/最近上屏历史
│   ├── next_words_big.lua                # 语料 bigram 联想模型
│   ├── next_words_tri.lua                # 语料 trigram 联想模型
│   ├── predict_space.lua                 # 连打键上屏联想
│   ├── select_character.lua              # 以词定字
│   ├── auto_commit.lua                   # 自动上屏兜底
│   └── …（共 24 个模块）
└── skins/
    └── 多功能大包-计算版-v106-以词定字.cskin   # 笔画键盘皮肤
```

## 🚀 安装部署

1. 将本仓库方案文件（`stroke_bg5cgq_learning.schema.yaml`、`stroke_bg5cgq.dict.yaml`、`lua/` 等）复制到元书的 Rime 用户目录
2. 导入皮肤：元书 → 设置 → 皮肤 → 导入 `多功能大包-计算版-v106-以词定字.cskin`
3. 在元书中**重新部署方案**（首次加载词库约 10 秒，一次性）

> 若修改了 `lua/` 中的模块，请重新覆盖并再次部署。

## 🎹 皮肤功能键

| 键位 | 功能 |
|---|---|
| 下移键（点击） | 候选下移 |
| 下移键（上滑） | 候选上移 |
| 降权键（点击） | 候选降权（沉底） |
| 降权键（上滑/下滑） | 重置 / 置顶 |
| 「首」键（! 位） | 以词定字取首字 |
| 「末」键（? 位） | 以词定字取末字 |
| 「连打」键（第 3 行） | 联想连打上屏 |
| 颜文字键 | 颜文字面板 |
