# 快捷指令定时自动备份元书方案（每日 23:00）

> 适用于：元书输入法（Hamster3 离线版）· iOS 快捷指令
> 目标：每天 23:00 自动把元书完整方案 + 用户数据备份到 iCloud Drive（或 WebDAV）

---

## 一、原理说明（重要）

元书内置「备份/恢复」功能支持 iCloud / WebDAV，但**没有向快捷指令开放触发接口**（快捷指令无法代替你点击元书内的备份按钮）。因此自动化采用**文件级备份**：

- 元书的全部数据都在 App 的 Documents 目录，在「文件」App 中显示为 **「我的 iPhone → 元书」**；
- 快捷指令每天定时把该目录**压缩为 zip**，保存到 **iCloud Drive**（或上传到 **WebDAV**）；
- 恢复时：解压 zip → 替换元书数据目录 → 在元书中重新部署，效果与元书内置备份一致。

备份内容（即元书方案目录）包括：

| 内容 | 说明 |
|---|---|
| `lua/*.lua` | 全部方案逻辑（检索/联想/自动上屏等） |
| `*.dict.yaml`、`dicts/` | 码表与词库 |
| `predict.db` | 用户历史预测 |
| `bg5-learning.user.tsv` 等用户数据 | 自学习调频、ngram、降权记录 |
| `installation.yaml`、`default.custom.yaml` 等 | 方案配置 |

## 二、推荐方案：Scriptable 脚本（无需未签名导入）

用 **Scriptable**（App Store 免费）写一份真正的脚本，快捷指令只需手动添加官方动作 **「运行 Scriptable 脚本」** 来调用它，**完全绕开 iOS「不支持未签名快捷指令」的限制**。仓库内已备好两份脚本：

| 文件 | 备份目的地 |
|---|---|
| `docs/元书自动备份-iCloud.js` | iCloud Drive/Scriptable/元书备份/日期/（推荐） |
| `docs/元书自动备份-WebDAV.js` | WebDAV 服务器（坚果云/Nextcloud/NAS） |

### 使用步骤（以 iCloud 版为例）

1. **安装 Scriptable**：App Store 搜索「Scriptable」安装；
2. **导入脚本**：把 `元书自动备份-iCloud.js` 发到 iPhone（AirDrop / 文件 App）→ 用 **Scriptable** 打开导入；
3. **首次运行**：在 Scriptable App 里点脚本 ▶ 运行 → 弹出文件夹选择器时选 **「我的 iPhone → 元书」**（只选一次，自动记住）；
4. **创建快捷指令**：快捷指令 App → 新建快捷指令 → 添加动作 **「运行 Scriptable 脚本」** → 选择 **「元书自动备份-iCloud」**；
5. **自动化**：快捷指令 → 自动化 → 个人自动化 → **特定时间 23:00 / 每天** → 「运行快捷指令」→ 选刚建的快捷指令 → **关闭「运行前询问」**。

> 💡 iCloud 版备份为**文件夹复制**（不压缩），自动保留最近 30 份并清理旧备份。完成/失败会发系统通知。

## 三、方案 A：备份到 iCloud Drive（快捷指令手动版）

### A1. 准备

1. 打开 iOS「文件」App，确认 **「我的 iPhone → 元书」** 目录存在（能看到 `lua`、`*.dict.yaml` 等文件）。
   - 如果看不到，说明元书未开启「文件共享」，请先到元书设置里检查是否有「在文件 App 中显示」开关（或确认元书版本支持）。
2. 在 iCloud Drive 下新建文件夹 **「元书备份」**（用于存放 zip）。

### A2. 核心动作一览（共 6 步）

| # | 动作 | 关键设置 |
|---|---|---|
| 1 | **获取文件夹内容** | 文件夹：我的 iPhone → 元书；打开「包括子文件夹」 |
| 2 | **制作归档** | 格式：zip |
| 3 | **当前日期** | 默认 |
| 4 | **格式化日期** | 格式：`yyyy-MM-dd-HHmm`（自定义） |
| 5 | **文本** | `元书备份-` + 日期变量（如 `元书备份-20261024-2300`） |
| 6 | **存储文件** | 位置：iCloud Drive；路径：`元书备份`；关闭「询问存储位置」 |

### A3. 创建快捷指令（详细步骤）

打开「快捷指令」App → 右上角 **+** → 新建快捷指令，命名为 **「元书自动备份-iCloud」**，然后按顺序添加动作：

1. **获取文件夹内容**
   - 点动作里的文件夹图标 → 选择 **「我的 iPhone → 元书」**；
   - 打开「**包括子文件夹**」开关（否则 lua、dicts 等子目录不会被备份）。
2. **制作归档**
   - 格式选 **「zip」**（默认）；
   - 文件名留空（后续用变量命名）。
3. **格式化日期**（为了每次备份文件名不同）
   - 输入：当前日期（可用「当前日期」动作提供）；
   - 格式：`yyyy-MM-dd-HHmm`（自定义）。
4. **文本**
   - 内容：`元书备份-` 后接「格式化日期」变量 → 得到如 `元书备份-2026-10-24-2300`。
5. **存储文件**
   - 位置：**iCloud Drive**；
   - 路径：`元书备份`；
   - 关闭「询问存储位置」；
   - 文件名：不覆盖同名文件（如果存在则自动加数字后缀），或开启覆盖。

> 💡 也可以直接用「制作归档」的默认文件名（如「归档.zip」），但每次会覆盖，只保留最新一份。想留历史版本就用上面的日期变量。

完成后点右下角 **▶ 运行** 测试：应能在 iCloud Drive/元书备份/ 看到生成的 zip，且 zip 内包含完整的 `lua`、`dicts` 等目录结构。

### A4. 创建每日 23:00 自动化

1. 快捷指令 App → 底部 **「自动化」** 标签 → 右上角 **+** → **「创建个人自动化」**；
2. 选择 **「特定时间」** → 时间设为 **23:00**，重复选 **「每天」**；
3. 点「下一步」→ **「添加操作」** → 搜索 **「运行快捷指令」** → 选择刚创建的 **「元书自动备份-iCloud」**；
4. **关键：关闭「运行前询问」开关**（否则每天 23:00 会弹窗要你确认，达不到全自动）；
5. 完成。

> ⚠️ 个人自动化在系统允许时运行（需要 iPhone 解锁/联网/充电状态满足系统条件）。若当天 23:00 设备在锁屏且系统判定低功耗，可能延迟执行，属正常现象。

## 四、方案 B：备份到 WebDAV（快捷指令手动版）

适合有坚果云 / Nextcloud / 群晖 NAS 的用户，备份不占 iCloud 空间。

### B1. 准备 WebDAV

1. 在 WebDAV 服务器上创建目录 **「元书备份」**：
   - 坚果云：网页版登录 → 新建文件夹 `元书备份`；
   - Nextcloud / NAS：在 Web 界面或客户端新建。
2. 获取认证信息：
   - 坚果云：登录网页 → 右上角头像 → **「账户信息」→「安全选项」→「添加应用密码」**，生成后得到 16 位应用密码（形如 `abcd-efgh-ijkl-mnop`）；
   - WebDAV 地址：`https://dav.jianguoyun.com/dav/`。

### B2. 生成 Basic Auth 字符串

`获取 URL 内容` 需要 `Authorization: Basic <base64>` 请求头，值为 **`用户名:应用密码`** 的 Base64。

可在电脑上执行：

```bash
echo -n "你的坚果云邮箱:应用密码" | base64
```

得到形如 `dXNlcm5hbWU6cGFzc3dvcmQ=` 的字符串，记下来。

### B3. 创建快捷指令

新建快捷指令 **「元书自动备份-WebDAV」**，动作：

1-4. 同方案 A：**获取文件夹内容**（我的 iPhone/元书，含子文件夹）→ **制作归档**（zip）→ 格式化日期 → 文本拼接文件名；
5. **获取 URL 内容**：
   - URL：`https://dav.jianguoyun.com/dav/元书备份/元书备份-20261024-2300.zip`（URL 中的中文一般可用；如报错请用 `文件` App 的 WebDAV 连接验证路径）；
   - 方法：**PUT**；
   - 请求头：添加一项，`Authorization` = `Basic <上面生成的base64>`；
   - 请求体：**文件** → 选择上一步「制作归档」输出的 zip；
   - 高级 → 关闭「跟随重定向」？不需要，保持默认。
6. 自动化设置同 A3（每日 23:00 运行）。

> 💡 首次使用建议先手动运行一次，确认 WebDAV 上出现 zip。坚果云免费版有上传流量限制，23:00 备份一次完全够用。

## 五、恢复方法（两种方案通用）

1. 在 iCloud Drive / WebDAV 中找到备份 zip；
2. 下载并用「文件」App 解压，得到方案文件夹；
3. 把解压内容整体替换到 **「我的 iPhone → 元书」** 目录（可先备份当前目录再替换）；
4. 打开元书 → 重新部署方案，用户数据（自学习、predict.db 等）随备份恢复。

## 六、常见问题

| 问题 | 解决办法 |
|---|---|
| 「文件」App 里看不到「我的 iPhone → 元书」 | 确认元书版本支持文件共享；可在元书内先用「备份导出」确认备份可用，再检查文件 App 显示设置 |
| 生成的 zip 里没有 lua/dicts 子目录 | 「获取文件夹内容」没开「包括子文件夹」 |
| 自动化到点没运行 | 检查「运行前询问」是否关闭；检查快捷指令 App 的通知权限；iPhone 是否在充电/联网；个人自动化可能被系统延迟 |
| 备份 zip 太大 | 主要体积来自 `predict.db`（约 7MB）+ 码表（约 15MB），总共约 20-30MB，属正常；若不想备份 predict.db 可在快捷指令里用「过滤文件」排除 |
| 想备份到 iCloud 但 iCloud 空间不足 | 改用方案 B（WebDAV） |
| WebDAV 上传报 401/403 | 检查 Basic Auth 是否用「应用密码」、用户名是否邮箱全名 |
| WebDAV 上传报 409/404 | 服务器目录 `元书备份` 未创建；或路径中有中文导致编码问题（可把目录改成英文 `yuan-backup`） |

## 七、关于仓库内的 `.shortcut` 文件（未签名导入说明）

仓库另附 `docs/元书自动备份-iCloud.shortcut`（6 动作版）。但 iOS 默认**不支持未签名快捷指令**，直接导入会提示「不支持未签名的快捷指令」。若仍想用文件导入：

1. 先在「快捷指令」App 里**运行任意一个快捷指令**（官方要求，一次即可）；
2. 打开 iOS **设置 → 快捷指令 → 允许不受信任的快捷指令**（开关变灰说明第 1 步未完成）；
3. 把 `.shortcut` 文件发到 iPhone（AirDrop / 文件 App）→ 用「快捷指令」打开 → 按提示允许导入；
4. 导入后仍需按 **A4** 手动创建每日 23:00 自动化。

> 🔒 **不想开启「允许不受信任的快捷指令」（更安全）**：直接按 **A2/A3** 手动创建，共 6 个动作、约 5 分钟，效果完全一样。
