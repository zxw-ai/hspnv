# 十五键笔画打字教程

配套练习：[练习.html](minis://workspace/%E5%8D%81%E4%BA%94%E9%94%AE/%E5%8D%81%E4%BA%94%E9%94%AE%E6%96%B9%E6%A1%88/%E7%BB%83%E4%B9%A0.html)（手机浏览器直接打开，两种模式：单字 / 词组）

总时长约 2 小时可以脱离提示。第 3 天开始能盲打。

---

## 第 0 步：先装好（5 分钟）

1. `shiwu.schema.yaml`、`shiwu.dict.yaml` 放进 Rime 用户目录
2. `十五键笔画-双义.cskin` 导入皮肤
3. 元书里重新部署，选「十五键笔画」

装好后先打几个字确认：`的`＝gtqdt，`我`＝mwqte。打不出来就是没部署成功。

---

## 第 1 步：认识 15 个键（10 分钟）

第一行是**五个单笔**，和传统笔画输入法完全一样：

```
一 q    丨 w    丿 e    丶 r    乛 t
```

第二、三行是**十个部件**，每个键代表「固定的几笔组合」：

```
十 a    口 s    厂 d    亠 f    亻 g
讠 h    勹 j    扌 k    了 l    禾头 m
```

**关键理解**：部件键的价值是「一键打完几笔」。看到「扌」按 k，比按 横竖提 三下少两键。

练习：先背这张表，然后打开练习网页的「单字」模式——屏幕上会显示每个码对应的部件名，你按提示找键，找的过程中自然就记住了。

记忆口诀（按字形联想）：

| 键 | 记忆方法 |
|---|---|
| a 十 | 一竖穿过一横，最简单的交叉 |
| s 口 | 一个方框，竖、折、横围起来 |
| d 厂 | 一横一撇，就是个「厂」 |
| f 亠 | 一点一横，盖在头上的「亠」 |
| g 亻 | 一撇一竖，站着的单人旁 |
| h 讠 | 一点一折，言字旁的第一笔 |
| j 勹 | 一撇一折，包字头 |
| k 扌 | 横、竖、提，提手旁 |
| l 了 | 竖折，就是个「了」 |
| m 禾头 | 撇横，禾苗的头 |

## 第 2 步：单笔打完整字（20 分钟）

**规则：按书写顺序，一笔一键，最多 5 码，不足 5 码补最后一笔的码。**

例：

```
人 = 撇 点        → 3 4   → e r   → 补码 errrr
一 = 横           → 1     → q     → 补码 qqqqq
大 = 横 撇 点     → 1 3 4 → 13 是「厂」！→ d + r → drrrr
```

注意最后一例：`13` 刚好是部件「厂」，所以 134 压缩成 `dr`，不是 `qer`。**码表按最长匹配，先看能不能凑成部件。**

补码的用处：任何字都能凑够 5 键，不会因为字笔画少而「打不满」。

练习：练习网页「单字」模式，前 50 个字全是高频字，慢慢打，看屏幕上的提示（每个码对应的部件名）。

**这一阶段不要追求速度**，重点是把「看到字形 → 想到笔画顺序 → 找到键位」这条链路走顺。

---

## 第 3 步：加入部件（30 分钟）

打完整笔画太慢，这一步学「用部件键省按键」。

例：

```
你 = 3 2 3 5 2 3 4
   32 → g（亻）
   35 → j（勹）
   2  → w（单笔竖）
   3  → e（单笔撇）
   4  → r（单笔点）
   全码 = gjwer

国 = 2 5 1 1 2 1 4 1
   251 → s（口）
   121 → k（扌/土）
   41  → f（亠）
   41  → f
   补码 f
   全码 = skfff
```

**怎么判断用不用部件？** 看码表里有没有。练习网页的提示会直接告诉你每个码是单笔还是部件。

判断原则：

- 字的开头如果是「亻、扌、讠、口、十、厂、亠、勹、了、禾」这 10 种结构，**直接按部件键**
- 其它结构（如 氵、艹、木、女）**没有专用键**，老实按单笔

例：

```
海 = 4 4 1 3 1 5 5 4 4 4
  4  → r（单笔点）
  41 → f（亠）
  31 → m（禾头）
  5  → t（单笔折）
  5  → t
  全码 = rfmtt

这里面有个反直觉的地方：氵不是被当成「点点提」三笔，
而是 4 + 41 + ...（第二个点跟了横读成「亠」）。
所以**不要按直觉推码，看练习网页的提示**。
```

> 这也是十五键与二十键的区别：二十键多了 氵彐八禾艹 五个键，所以「海」在二十键里可以按 z（氵）。

练习：练习网页「单字」模式，练到能连续打对 20 个字不看提示。

## 第 4 步：词组（20 分钟）

**规则**：

| 词长 | 取码 | 例 |
|---|---|---|
| 2 字 | 首字前 2 + 次字前 3 | 中国 = sw + skf = **swskf** |
| 3 字 | 1 + 2 + 2 | 图书馆 = w + tl + jt = **wtljt** |
| 4 字 | 1 + 1 + 1 + 2 | 人工智能 = e + k + m + tr = **ekmtr** |
| 5 字以上 | 前四字首码 + 末字首码 | — |

打出词组比单字快得多：一个 2 字词 5 键就出来，比打两次单字（10 键）省一半。

例：

```
我们 = 我(mw) + 们(grw) = mwgrw
可以 = 可(at) + 以(tre) = attre
什么 = 什(ga) + 么(jrr) = gajrr
```

练习：练习网页「词组」模式，127 个常用词。

---

## 第 5 步：简码（10 分钟）

1-4 码各有一个最高频字，**不用打满 5 码就出**：

```
g  → 的
gt → 的
gtq → 的
条 gxdt → 的
```

实际上只要打 1 键「g」，「的」就在首位。

**提速技巧**：打常用字时，看到首位是自己要的字，直接按空格上屏，不用打满。

高频简码表（记住前 10 个能提速 30%）：

| 简码 | 字 | 简码 | 字 |
|---|---|---|---|
| g | 的 | m | 我 |
| s | 是 | d | 在 |
| a | 要 | l | 了 |
| q | 一 | w | 不 |
| e | 个 | r | 这 |

---

## 第 6 步：通配与救急（5 分钟）

**通配键 `*`**：忘记某一位时用它。

```
g*d   → 首码 g、第 3 码 d 的所有字（偏、顺、侯…）
*tqdt → 忘记首码时打「的」
```

**重码怎么办**：打完 5 码如果首位不是你要的字，按**数字键**选（1-9）。这是用字母做编码的好处，数字键空出来了。

**打错重来**：皮肤上的「重输」键清空输入。

## 每日练习计划

| 天 | 内容 | 目标 |
|---|---|---|
| 第 1 天 | 单字 50 题（看提示打） | 15 个键全对 |
| 第 2 天 | 单字 100 题 | 速度 10 字/分 |
| 第 3 天 | 单字 100 + 词组 50 | 速度 20 字/分，不看键盘 |
| 第 4 天 | 词组 100 | 速度 30 字/分 |
| 第 5 天 | 混合练习 | 速度 40 字/分 |

参考速度：熟练后单字约 5 秒/字（5 码 + 选字），词组约 3 秒/词。这个方案不比拼音快，优势是**不需要知道读音**。

## 常见问题

**Q：为什么「的」是 gtqdt 而不是按笔画？**
A：gtqdt = 亻(g) + 折(t) + 一(q) + 厂(d) + 折(t)。这不是严格的笔画顺序，是压缩算法的结果（32→g，5→t，1→q，13→d，5→t）。**编码以码表为准，不要自己推导**。

**Q：打「氵」按什么？**
A：没有专用键，按 点点提 三下（r r q）。这是十五键的取舍——要 20 键才有『氵』键。

**Q：为什么有时候按 3 键就出字了？**
A：那是简码（前三码恰好匹配某个高频字）。

**Q：数字键不能选字？**
A：可以。本方案用字母编码，数字 1-9 专用于选候选。

**Q：字打不出来？**
A：可能不在 17,204 字表里（生僻字/扩展区）。这些字方案不支持。
