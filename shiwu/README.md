# 十五键笔画输入法 v1.0（元书 / Hamster 版）

15 键 = 5 个单笔键 + 10 个部件键。比传统五笔画少按一半键，比十笔画多 9-27 个百分点的首选率。

## 实测数据

同一字集（7,319 字）与词库（179,944 词）对比：

| 方案 | 单字5码首选 | 2字词 | 3字词 | 4字词 |
|---|---|---|---|---|
| 五笔画 | 15.5% | 30.9% | 18.8% | 29.9% |
| 十笔画 | 50.9% | 52.7% | 62.3% | 62.9% |
| **十五键** | **60.5%** | **74.4%** | **85.4%** | **90.6%** |

单字 6 码首选 77.1%。词频加权，按词频随机抽一个词，它排在同码组第一的概率。

## 键位表

```
第1行  ， 一(q)  丨(w)  丿(e)  丶(r)  乛(t)  ⌫
第2行  。 十(a)  口(s)  厂(d)  亠(f)  亻(g)  重输
第3行  ？ 讠(h)  勹(j)  扌(k)  了(l)  禾头(m) 通配
第4行  符号 123 空格 中英 发送
```

按键发字母，皮肤显示部件名。用字母不用数字，是为了保住数字键的候选选择功能。

## 编码规则

**单字**：按书写顺序，每笔或每个部件按一键；最长 5 码，不足补末码。

**词组**：
- 2 字：首字前 2 码 + 次字前 3 码
- 3 字：1 + 2 + 2
- 4 字：1 + 1 + 1 + 2
- 5 字及以上：前四字首码 + 末字首码

**简码**：1-4 码各取最高频字（的=g、我=m、是=s、在=d…）。

## 部件对照

| 键 | 名称 | 笔画序列 | 典型字 |
|---|---|---|---|
| a | 十 | 横竖 | 十、土、工、干、于 |
| s | 口 | 竖折横 | 口、日、只、中 |
| d | 厂 | 横撇 | 厂、石、百、大 |
| f | 亠 | 点横 | 言、京、高、市 |
| g | 亻 | 撇竖 | 你、他、们、做 |
| h | 讠 | 点折 | 讠、忄、门、问 |
| j | 勹 | 撇折 | 包、句、勺、勿 |
| k | 扌 | 横竖提 | 扌、土、王、丰 |
| l | 了 | 竖折 | 了、子、也、出 |
| m | 禾头 | 撇横 | 禾、看、年、手 |

部件按书写笔画序列自动匹配，不需要记名字——看到「扌」按 k（1 键打完 3 笔），看到「氵」没有专用键就按 点点提 三键。

## 与二十键的取舍

| | 十五键 | 二十键 |
|---|---|---|
| 键数 | 15（3 行） | 20（4 行） |
| 单字5码首选 | 60.5% | 73.0% |
| 2字词 | 74.4% | 82.0% |
| 4字词 | 90.6% | 94.4% |
| 部件数 | 10 | 15 |

二十键多出的 5 个部件（氵彐八禾艹）合计贡献约 +6~12pt。如果觉得 4 行键盘太高，十五键是更好的平衡点。

## 安装（元书）

1. `shiwu.schema.yaml`、`shiwu.dict.yaml` 放进 Rime 用户目录。
2. `十五键笔画-双义.cskin` 用皮肤导入功能加载。
3. 重新部署，选方案「十五键笔画」。

首次部署编译 199,626 条词典，约十几秒。

## 已知限制

- 字表 17,204 字（hspnv 五笔画字表）。十笔画方案有 20,901 字，缺的主要是生僻字。
- 单字 5 码平均 1.65 字/码，重码靠词频排序。
- 部件按最长匹配，`了`(52) 与 `子` 共用一码。

## 通配符

皮肤第 3 行右侧的「通配」键发送 `*`。输入里任意位置放 `*` 可以匹配任意一个码：

- `g*d` → g 开头、第 3 码是 d 的所有字（偏、顺、侯…）
- `*tqdt` → 忘记首码时打「的」（gtqdt）
- `gtq*` → 前缀不确定时

实现是 Lua 展开 + 索引查询（`lua/shiwu_wild.lua` + `lua/shiwu_wild/idx.bin` 3.4MB）。最多展开两个通配（约 110ms），三个以上会忽略多余的 `*` 以免卡顿。

### 通配实现要点（踩坑记录）

1. Rime 的 `table_translator` **不支持** `*` / `?` 通配（实测 1.17 版本，`g*d` 无任何候选），只能走 Lua。
2. `lua_translator@模块` 必须写成 **`lua_translator@*模块`**（星号前缀 = 可选组件，加载失败不阻断；不带星号时静默跳过，表现为“能输入但无候选”）。
3. Lua 的 `io.open` 相对路径基准不可靠，必须用 `rime_api.get_user_data_dir()` 拼绝对路径：
   ```lua
   local ok, ud = pcall(function() return rime_api.get_user_data_dir() end)
   db = kvdb.open(ud .. '/lua/shiwu_wild/idx.bin')
   ```
4. 模块名不能和同名目录冲突（`shiwu_wild.lua` vs `shiwu_wild/`），改名为 `shiwu_wild_t.lua`。
5. 通配按**精确码长**匹配（`g*t` 只出 3 码字），不做前缀展开，避免响应变慢。
