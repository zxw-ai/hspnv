# 十五键笔画 · 口诀

背口诀顺序：**键位诀 → 拆字诀 → 识别诀 → 易错诀**。四段背熟，拆字不用查表。

---

## 一、键位诀（记 15 个键在哪）

```
横竖撇点折，五个单笔排第一；
十口厂亠亻，讠勹扌了禾头齐。
```

节奏：**三字一顿**，念的时候手指跟着点。

```
q  w  e  r  t      ← 横 竖 撇 点 折
a  s  d  f  g      ← 十 口 厂 亠 亻
h  j  k  l  m      ← 讠 勹 扌 了 禾头
```

**第一排全单笔**（五个基本笔画），**二三排全部件**（十种常见结构）。分清楚这点，就不会把「口」和「丨」搞混。

---

## 二、拆字诀（记取码顺序）

```
左到右，上到下，笔顺别乱跳；
能凑长，不拆短，五码凑够就拉倒；
不够五，补末码，重复最后一笔好。
```

三句话对应三条规则：

| 句 | 规则 |
|---|---|
| 左到右，上到下 | 按标准笔顺扫描，不按偏旁语义 |
| 能凑长，不拆短 | 最长匹配：`1 3` 能凑「厂」就不按「一、撇」两键 |
| 不够五，补末码 | 不足 5 码重复最后一码：`人`=34→`errrr` |

---

## 三、识别诀（记十个部件长什么样）

```
横竖相遇就是十，
竖折横围成个口；
横撇相连认作厂，
点横相叠亠上头；
撇竖并排单人立，
点折一挑言字走；
撇折一钩勹字头，
横竖提来提手留；
竖折是了别认错，
撇横禾头楷书有。
```

每条对应一个键：

| 句 | 部件 | 键 | 笔画 |
|---|---|---|---|
| 横竖相遇就是十 | 十 | a | 12 |
| 竖折横围成个口 | 口 | s | 251 |
| 横撇相连认作厂 | 厂 | d | 13 |
| 点横相叠亠上头 | 亠 | f | 41 |
| 撇竖并排单人立 | 亻 | g | 32 |
| 点折一挑言字走 | 讠 | h | 45 |
| 撇折一钩勹字头 | 勹 | j | 35 |
| 横竖提来提手留 | 扌 | k | 121 |
| 竖折是了别认错 | 了 | l | 52 |
| 撇横禾头楷书有 | 禾头 | m | 31 |

**记法**：五言两句一组，第一个字就是笔画序列的第一个数字——「横竖」=12、「竖折横」=251，念的时候顺手就把码记住了。

## 四、易错诀（记最容易拆错的字）

```
大不有，厂开头；
我去禾头莫乱拆；
去是扌，没带亠；
是口加扌记清白。
```

| 句 | 字 | 正确拆法 |
|---|---|---|
| 大不有，厂开头 | 大 | `1 3` 是厂 → d + r = **drrrr** |
| | 不 | 同上 → **dwrrr** |
| | 有 | 厂 + 口 + 一 → **dsqqq** |
| 我去禾头莫乱拆 | 我 | `3 1` 是禾头 → m + w + q + t + e = **mwqte** |
| | 去 | `1 2 1` 是扌 → **ktrrr** |
| 没带亠 | 没 | 第二码是亠 → **rfjtr** |
| 是口加扌记清白 | 是 | 口(251) + 一 + 扌(121) + 撇 + 点 = **sqker** |

## 五、笔顺诀（通用写字顺序）

拆字的前提是笔顺正确。标准笔顺规则：

```
先横后竖，先撇后点；
从上到下，从左到右；
先外后内，先中间后两边；
封口最后写，点在末尾添。
```

这四句是教育部《现代汉语通用字笔顺规范》的基本规则：

- **先横后竖**：十（一在前，丨在后）
- **先撇后点**：八、人
- **从上到下**：三、言
- **从左到右**：川、州
- **先外后内**：月、同
- **先中间后两边**：小、水
- **封口最后**：国（先写里面，最后封底横）
- **点在最后**：犬、术

笔顺错了，拆出来的码一定错。**不确定笔顺时，用通配 `*` 试**。

## 附：三个常见误区

**以为"先写偏旁"** —— 不是。比如「想」不先写「木」，是按笔顺从左上扫到右下。

**以为部件必须完整** —— 不是。「没」的氵没有被当成整体，第二个点跟后面的横凑成了「亠」。

**以为码越长越准** —— 不是。5 码满就停，后面笔画根本不看。比如「的」有 8 笔，第 6 笔以后不参与编码。
